# Nail Candy — mobile-first manicure landing page

A static, responsive Russian-language landing page with a glossy blush-pink palette, candy-like 3D buttons, nail photography, service cards, and a demo booking modal.

## Preview locally
Open `index.html` in a browser. The page uses Google Fonts and Unsplash image URLs, so an internet connection is needed for those assets.

## Netlify
Publish directory: `nail-candy-mobile` when this repository is connected to the `nail-candy-mobile` branch. No build command is required for this static page.

## Before real launch
- Replace demo prices and copy with the artist's actual details.
- Replace social links and add a real booking destination.
- Connect the form to Netlify Forms or a booking service. Current form only demonstrates the interaction and does not transmit submissions.
- Confirm image licensing/availability and replace any photos as needed.
